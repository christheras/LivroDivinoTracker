Patch notes: Rastreador de Livros Divinos (03/11/2026)

Novidades

Barra de progresso em blocos: a barra de cada cartão agora tem um bloco por livro necessário. Se precisa de 15, são 15 blocos, e cada livro forjado acende um bloco.
Ingredientes em blocos: a receita de cada cartão também ganhou barras em blocos, um bloco por livro que falta. Os blocos acendem conforme você tem o material.
Botão de modo escuro e claro: novo botão flutuante no canto superior direito. A escolha fica salva no navegador. Na primeira visita, a página segue o tema do aparelho.

Melhorias visuais

Ingrediente pronto em verde forte: quando você já tem todo o material de um ingrediente, a linha inteira fica verde, com texto branco, para ficar fácil de ver.
Roxo azulado quando dá para forjar: quando você tem material dos 3 ingredientes de um livro, as 3 linhas ficam roxo azulado, junto com o aviso “Dá para forjar agora”.
